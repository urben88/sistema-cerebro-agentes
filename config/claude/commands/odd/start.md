Tarea: $ARGUMENTS

Sigue el flujo ODD en orden, sin saltarte pasos:

1. **Authorize:** confirma si la tarea autoriza cambios. Si no está claro, pregunta una sola cosa y espera.
2. **Explore:** mapea lo necesario. Si es mucho, delega en `explorador` (tabla de reparto de CLAUDE.md).
3. **Classify:** pequeña (inline) o grande (documento `odd/tasks/<nombre>.md` + espejo en Engram).
4. **Track → Implement → Close:** trabaja tarea a tarea, verifica y cierra con la línea `Risk:`.

Reparto barato: usa la tabla de CLAUDE.md. Resume al final: resultado, qué falló o quedó pendiente y siguiente paso.
