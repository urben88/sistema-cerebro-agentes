# Sonidos

Pon aquí el sonido que suena cuando Claude termina de responder:

- `fin.mp3`, `fin.wav` o `fin.ogg` (suena el primero que exista, en ese orden).
- Sin archivo suena el sonido del sistema.
- Se instala en `~/.sistema-cerebro-agentes/sonidos/`. El instalador no borra tus archivos.
- Apagarlo: `"sonido_fin": false` en `hub-data/reglas.json`.

El sistema no descarga audio: el archivo lo pones tú.
